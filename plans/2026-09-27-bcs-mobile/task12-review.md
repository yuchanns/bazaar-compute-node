# Task 12 验收记录（2026-09-27）

统一订阅轮询已接入。浏览器保存订阅与展示进度，BCS 每次按请求查询已有持久化数据；服务端没有客户端订阅表或内存版本总线。

## 实现落点

| 消费区域 | 检查与更新 |
| --- | --- |
| 智能体、电脑列表 | agents/computers 只比较成员和分页范围；改变姓名/图标/版本由 agent-info/computer-info 读取单行或头部 |
| 智能体侧栏、详情、电脑 roster、悬浮卡状态 | agent-status 通知直接更新 Alpine 数据，不替换状态灯 DOM |
| 电脑灯、最近上报基准、队列、添加按钮、接入提示 | computer-state 直接消费 online/last_event_at_ms/queued；电脑详情的成员/元数据另订阅 computer |
| 会话、审核数量、消息流、活动流 | contacts/messages/events 通知后读取原片段；保留分页、滚动、选中项和实际已展示游标 |
| 悬浮卡 | 悬停时订阅 activity；离开时注销；状态灯另外消费共享状态通知 |
| 健康与用量 | health 检查健康摘要、usage 游标和当前日期；仅打开状态标签时读取 |
| 会话抽屉提醒 | reminders 覆盖建立、延期、修改、取消、触发事件；抽屉打开时才订阅，仅替换提醒小区 |
| 所有相对时间 | clock 每秒本地更新联系人、电脑、文件时间，以及渠道、活动卡、审核、提醒的日期文字；新增时间基准来自实际数据 |
| 当前会话名称 | 联系人片段更新后同步聊天、抽屉名称及后续 profile URL；使用文本绑定 |

`poll.js` 统一管理一个调度循环，网络检查间隔为上次请求完成后 5 秒。网络响应仅由管理器解析、匹配，再并发调用订阅回调；一个片段的慢请求不阻塞其他消费者或本地时钟。相同 scope/seen 合并发送，消费者各自确认成功状态；销毁、换 scope、晚到结果通过注销和 generation 隔离。

原八类 `hx-trigger="every 5s"` 均已移除。用户点击、初始加载、分页和一次性反馈继续使用原入口。skills 和工作区内容沿用打开/显式刷新时的快照语义，文件时间接入本地时钟。

## 已执行验证

- 真实临时 SQLite/API：静默、普通事件、工作状态、成员摘要独立性、跨账号可见范围及单项 unavailable。
- 浏览器静默活动页 30 秒：只有 5 次 `/poll`，没有列表或活动片段 GET。
- 工作状态变化：侧栏、详情两个灯变 busy，原 DOM 身份保持；没有 list/row/head 请求。
- 一批 121 条活动：按每页 50 条追平，全部可见。静默与该批活动合计观察窗口内 9 次 `/poll`、4 次 events GET（包含工作开始事件），列表请求为 0。
- 改名更新 row/head；增加成员才刷新列表。切离活动标签后不再读取 events。
- 联系人和电脑时间在无新内容时自动改变；电脑示例从 just now 到 19s ago，没有为时间变化重取列表。
- 真实 TestChannel 入站、审核、运行时命令发送回复，并建立提醒；抽屉原节点保留。延期、改名、取消逐项通过真实命令服务驱动并检查页面变化。
- 网络实际离线/恢复；停止专用测试节点并等待真实 120 秒心跳阈值，状态灯离线；重启该节点恢复。
- 同端口、同数据库重启专用 BCS；保留浏览器进度并收到新状态，原列表行保留。旧 X-Build 触发 stale 提示并停止轮询。
- 健康错误与用量报告使状态页自动更新；电脑队列变为 7，电脑列表行及详情节点身份保持。
- Task 11 的真实浏览器详情回归脚本再次通过 63 项检查，覆盖响应式导航、聊天、抽屉、技能/文件、表单与错误界面。

所有服务、数据库、节点和 Channel 均为专用隔离测试实例。浏览器为本机 Edge，包含桌面与 390×844 响应式视口。

| 旧活动读取 | 9 | 2 | 11 |
